# 🧩 PromptSprite（提示精灵）

> AI 提示词管理工具 —— 把杂乱无章的 Prompt 文档，变成 **五级分类书架 + 极速检索 + 一键复制 + 回收站（可恢复）+ 每日变更包 + 导入导出安全防护** 的本地神器。

> 📁 **请把它放在一个稳定、可写、不会被误删的文件夹**（不要放桌面或"下载"文件夹），**数据就存在 EXE 同目录的 `data/` 里**——换文件夹/换电脑时，**把整个 `data` 文件夹一起复制过去**即可。
> 🔐 数据 100% 存在本机（明文 SQLite，**不含加密**，如有隐私需求建议配合 BitLocker 等系统级磁盘加密）；**只有你在向导里主动使用「从网址获取」、或在标签页面使用「热点词更新」时才会联网**（只读抓取你填写的网址，不写盘、不留登录态），其余功能全程离线。
> 📖 首次使用请先读 [《软件安装使用说明书 V13》](docs/20260922_软件安装使用说明书_v13.md)。

| ⑭ 每日变更包 | 每次关闭自动生成"当日全部变更"同步包：`变更包_{电脑代号}_{日期}_add{N}_del{M}.json`（**JSON v6**，兼容 v2 起全部旧格式；同日仅一份、保留天数可设）；**条目与删除项均带稳定 ID ⇒ 换机按 uuid 精确同步**（"修改"＝更新同一条、删除不误伤同内容条目）；可换机合并导入、可导出 Excel/HTML 浏览 |
| ⑮ 导入安全防护 | 含删除清单的包一律走**导入向导**：先预览（来源电脑/日期、新增/修改/删除计数、落后同步红字提示）→ 二维选择（是否合并新增修改；删除清单：忽略 / 正常应用（须输"确认删除"）/ ⑤ 逆向恢复（须输"恢复删除"））；**导入前自动快照**（`prompts_preimport_*.db`，可一键回滚）；被删条目先进回收站、保留图片 |

| ⑱ 界面与设置 | 工具栏 11 项功能按钮 + 搜索框；**🗂 目录隐藏/显示**可任选隐藏各分类列（窗口最小宽度动态化）；**✏️ 编辑 / 👁 浏览**切换（浏览态只读防误改）；设置 **6 页分页**：界面 / 外观 / 数据与备份 / 字段 / 标签与词表 / 关于（含版本、库数据统计、功能与使用说明、可点击的开源仓库链接） |

## 🚀 快速开始

### 方式一：直接使用（普通用户）

1. 从 [GitHub Releases](https://github.com/yihufree/PromptSprite/releases) 下载 `PromptSprite_<打包日期YYMMDD>_V<版本号>.exe`（**以 Releases 页最新标注为准**）；
2. **放到一个你记得住、不会被误删的文件夹**（**不要放桌面或"下载"文件夹**），双击运行（首次自动建库并导入内置数据；数据保存在 EXE 同目录 `data/` 下）；**换文件夹时请把原来的 `data` 文件夹一起复制过去**；
3. 详细图文说明见 [《软件安装使用说明书 V13》](docs/20260922_软件安装使用说明书_v13.md)。

### 方式二：源码运行（开发者）

```powershell
# 1. 克隆仓库
git clone https://github.com/yihufree/PromptSprite.git
cd PromptSprite

# 2. 创建虚拟环境并安装依赖（Python 3.12，兼容 3.10+）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. 启动（以下三种方式等价）
python app/main.py            # 直接运行主文件（推荐）
python run.py                 # 根目录启动器
python -m app.main --smoke    # 冒烟测试：5 秒后自动退出
```

运行依赖：`customtkinter` / `Pillow` / `pyperclip` / `openpyxl` / `keyboard` / `pystray`（见 [requirements.txt](requirements.txt)）。

### 📦 打包发布

```powershell
python build.py           # 一键打包（自动装依赖/生成图标/内嵌最新完整库/PyInstaller 单 EXE/校验）
```

产物自动按 **`PromptSprite_<打包日期YYMMDD>_V<版本号>.exe`** 命名（当前版本号 `2.3.0`，即 `..._V2.3.0.exe`；**体积与 SHA256 随每次构建而变**）。详见 [《打包发布指南 V12》](docs/20260922_打包发布指南_v12.md)。

> V2.1.0 ~ **V2.3.0** 三批增强**均未新增任何第三方依赖**（智能标签 / 批量打标 / 词表 / 热点词 / 自动取词 / 条目稳定 ID / 导出范围确认 / 批量删除均用标准库），因此**打包流程与 `spec` 无需改动**。
> ⚠️ 打包脚本含**硬门禁**：第 4.5 步会用 `clean_builtin_meta.py` 清理并复核内嵌库的"运行态 meta"（含开发机计算机名等），**任一步失败会直接终止打包**。

## 🗄️ 数据与隐私

- **100% 本地**：单文件 SQLite 数据库 `data/prompts.db`；打包态为 EXE 同目录 `data/`，开发态为项目根 `data/`。软件**不上传、不收集任何数据**；唯一的联网行为是你在结构化向导里**主动**使用「从网址获取」（或标签页面「热点词更新」）时按你填写的网址做**只读抓取**（不写盘源文件、不留登录态、不后台访问、不做站内遍历）。
- **图片与备份**：条目关联图片存 `data/images/`；自动全量备份、导入前 / 打标前 / 批量删除前快照存 `data/backup/`；每日变更包存 `data/backup/incremental/`。
- **数据模型**：项目类别/根目录/一级/二级/条目五级；分类为**全局共享树**（删除根目录仅解除关联）；`trash` 表保存被删完整快照（可恢复）；旧库启动自动迁移（幂等，迁移前自动备份）。
- **批量删除口令**：删除「项目类别」整枝时需输入**专用口令 `123456`**（公开默认口令，仅作"多一道手工关卡"；真正的数据兜底是**双重自动备份 + 回收站**）。软件内 **设置 → 关于 → 「查看完整说明」** 中亦有记载。
- **隐私提醒**：变更包可能包含条目内容与删除清单；"携带被删快照"默认关闭，分发/导入前请先查看摘要确认（纯删除包会有红字警告）。

## ⚠ 已知限制与说明（2026-09-22 **V2.3.0** 复核）

> 完整版（含每条限制的应对办法）见 [《软件安装使用说明书 V13》第 22 章](docs/20260922_软件安装使用说明书_v13.md)。

1. **搜索的 1.5 秒延迟是刻意设计**：输入过程不实时查询（避免整库刷新卡顿），停止输入约 1.5 秒后才搜索；要"立刻出结果"请点搜索框右侧 **🔍** 或按回车。
2. **窗口最小宽度随目录显隐变化**：四列全显示时约 1496、四列全隐藏时约 1104（下限由顶部工具栏"完整显示所需宽度"决定）。
3. **库结构 schema v5 / 导出格式 JSON v6（重要）**：旧库启动自动迁移（幂等、迁移前自动备份）；**回退到旧版 EXE 时必须同时恢复数据库备份**（旧版不认识新结构）。老导出文件（JSON v2~v5、旧 Excel、旧 MD）**照常可用**。
4. **多位置条目的导出往返（v6 起已保真）**：子树导出时多位置条目**只写一次**、位置清单写入 `locations`，导入自动重建关联；**例外**：Excel 仍按行展开（便于人看/人改），但导入时按 `uuid` 合并、不再产生副本；若表格被人为删掉 `uuid` 列，则退回"内容键"判重。
5. **「修改」的换机同步语义（v5 起已修正）**：条目带跨机器稳定 ID，变更包/JSON 导入优先按 uuid 匹配 ⇒「修改」＝**更新同一条目**；**旧包（v2~v5）行为不变**，仍按内容键合并。
6. **批量删除的边界**：被其他根目录共享的一级分类**只解除关联、不删除记录**；条目仅在**全部位置**都落在删除范围内时才删除本体，否则只解除范围内的位置关联。删除前的两份备份（全量库 + 分支 JSON）失败会**直接中止删除**。
7. **「项目类别」批量删除的口令是公开默认值 `123456`**：它的作用是"多一道手工关卡"，**不构成安全防护**；请勿把它当作权限控制。
8. **详情"自动"显示模式**：默认仅对 **视频 / 图像** 两个根目录完整显示 ②~⑦，其余根目录只显示 ② 介绍；点详情头部"⏵ 显示全部字段"或把设置改为"全部"即可全显。
9. **"手动隐藏"是硬隐藏**：无论显示模式如何，字段管理里被隐藏的区块都不显示，头部「显示全部字段」也**不会**恢复它（须回字段管理改回"显示"）；**内容不会丢**（照常导出、搜索、进变更包）。
10. **区块顺序 / 隐藏 / 外观属「本机偏好」**：存在本机数据库设置项里，**不随 JSON 包 / 变更包跨机同步**；用本机备份恢复会带回该设置。① 名称固定显示、不参与排序、不可隐藏。
11. **结构化向导的出口为"先保存数据文件、再导入"**：保存后若又改映射/换表/换源，需重新保存才能导入。
12. **联网抓取的边界**：不支持需要 JS 渲染的页面、不处理登录流程、不做风控绕过、不做站内自动遍历；抓取仅为你主动触发的**一次性只读请求**（15 秒超时、体积上限 10MB；GitHub 批量另有限额）。
13. **数据库为明文 SQLite，不含加密**：本机其它程序理论上可读取 `data/prompts.db`。**如有隐私需求，建议配合系统级磁盘加密（Windows BitLocker 等）**。
14. **自动取词的"词表阈值"提示只在管理对话框内出现**：软件不会主动弹窗，请偶尔打开"设置 → 标签与词表 → 🧠 自动取词词库…"查看"待审核"数量。
15. **调整字段顺序后没有"一键恢复默认"**：需手工用 ↑↓ 排回，**建议调整前先记录原顺序**。
16. **软件应放在稳定、可写、不会被误删的文件夹**：`data` 必须与程序同目录；换文件夹时请把原 `data` 一起复制过去，否则会新建空库。
17. **打包脚本含硬门禁**：`python build.py` 第 4.5 步会清理并复核内嵌库的"运行态 meta"，**任一步失败会直接终止打包**（刻意设计，请勿绕过）。

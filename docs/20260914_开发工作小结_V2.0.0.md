# PromptSprite2 开发工作小结（V2.0.0）

- 日期：2026-09-14
- 版本：**V2.0.0**（上一版 V1.9.0 / 2026-09-12）
- 范围：2026-09-13 ~ 2026-09-14 两天的全部改造（离线增强两期 + 联网抓取一期 + 审核与修复）
- 依据施工方案：

---

## 一、为什么

1. **数据组织能力不够用**：只有"五级分类 + 9 字段"，无法给条目打标签、无法一处分门别类地跨分类聚合；
   条目只能挂一张配图；字段不可自定义、更没有类型化（数字/日期/选项等）。
2. **网上资源整理全靠手工**：此前把网上资料变成库内条目的流程是"手工下载 → 手工清洗 → 粘贴导入"，
   步骤多、易漏，2026-08-18 的三次实践（共约 3700 条）证明"抓取 → 结构化 → 数据文件 → 导入"价值极高。
3. **上轮审核暴露数据安全缺口**：回收站批量入站、清空回收站、变更包等路径在"标签/自定义字段/图集"
   这类新数据上存在**静默丢数据**与**孤儿文件**风险，必须先修。

## 二、作用

| 作用     | 说明                                                          |
| ------ | ----------------------------------------------------------- |
| 组织更自由  | 标签跨分类聚合 + 标签页面（标签云/列表双呈现、且/或过滤）；自定义字段与 11 种类型               |
| 资料更丰富  | 条目"封面 + 图集"多图（本地/外链，可下载到本地）；短音频可试听、附件/图像可打开                 |
| 录入更高效  | 结构过滤（列表框三类数据源：序列 / 目录层级 / 条目），引用被删有占位提示而不是报错                |
| 整理半自动化 | 结构化向导（粘贴 / 文件 / **网址抓取**）→ 四层映射 → 字段映射 → **质量自检** → 先存文件再导入 |
| 换机更可靠  | 变更包随包携带字段定义；打标签/改自定义字段也会进当日变更包；回收站快照补全三类数据                  |
| 升级更省心  | 库结构 v4、JSON v5 均为"纯新增 + 向后兼容"，旧备份/旧导出文件照常导入，覆盖 EXE 即可       |

## 三、主要内容

### 第 1 期　字段元数据地基 + 标签 + 详情显示模式

- 新增 6 张表：`field_defs` / `entry_field_values` / `entry_ref_links` / `tags` / `entry_tags` / `entry_images`；
  schema v3 → **v4**（纯新增表、存量数据零迁移、幂等）。
- 字段管理对话框：内置 10 项可改名、不可删；自定义字段可增/删（归档隐藏）/改名/排序/**改类型**。
- 搜索纳入"自定义字段取值"与"标签名"；`#标签` 语法；自定义字段**不**参与内容判重键。
- 详情显示模式（自动/全部/精简）**真正生效**（此前设置无效），头部按钮可会话内临时覆盖。
- 标签系统：详情区标签区块、**标签页面**（工具栏 + 详情区底部两个入口、与四级目录互斥、
  标签云 ⇄ 列表＋计数、且/或过滤、重命名/合并/删除/清理未使用、`#标签` 可搜索）。

### 第 2 期　图片（封面 + 图集）

- 详情区 ⑦ 升级为"封面 + 图集"：本地图 / 外链图双源、排序、移除、"**下载到本地**"（保留来源网址）。
- 新建态"做法 B"：先内存暂存，保存成功才复制落盘（放弃不产生文件）；浏览态图片按钮真正置灰。
- 联动补齐：复制条目 / 复制子树 / 回收站恢复 / 彻底删除释放文件 / 变更包 / JSON·Excel·HTML 导出。

### 第 3 期　列表框数据源扩展

- `tree_level`（项目类别/根目录/一级/二级；整棵子树或指定节点、可带路径前缀）与
  `entries`（全部或某分类下）；失联引用显示"该项已经被删除（原：快照名）"；删除目录/条目前提示被引用情况。

### 第 4 期　离线"网上资源结构化"向导

- 通用层级导入器（**四层**：项目类别/根目录/一级/二级；空单元格继承、允许跳层并兜底）；
  `json_io` 同步扩到**四层路径**（存文件 / 导入两侧对称），格式升到 **v5**（兼容 v2/v3/v4）。
- 向导三步：选源 → 映射（层级 + 字段：内置 10 项 / 自定义字段 / 标签）→ 预览与出口
  （树预览 + 新增/复用/判重统计 → **先保存数据文件，再导入**；导入前自动快照、可一键回滚）。

### T2　联网抓取（5-a ~ 5-d）

- **5-a 抓取层**（纯标准库）：仅 http/https、浏览器 UA、Referer/Cookie、超时与重试、gzip/deflate、
  编码探测、体积上限、失败分类、反爬拦截页识别。
- **5-b 向导接入**：向导第 1 步三选源；抓取状态行（HTTP / 类型 / 体积 / 识别结果 / 通道）；
  多表页面"选表"；高级区（UA/Referer/Cookie/超时/上限）；**质量自检面板**；**链接补全**；**先存后导**。
- **5-c GitHub 目录批量**：目录列举 → 多选（默认勾选常见文档、显示体积）→ 逐个抓取（进度条）→
  合并（表头一致自动合并为一张表，不一致则提示逐文件处理）；限额（单文件 ≤2MB、一次 ≤20 个、合计 ≤20MB）；
  个别失败逐个跳过并列出。
- **5-d 四项增强**：关键词规则化二级分类（先匹配先得 + "其他"占比）、行筛选（包含/排除）、
  中英提示词自动分流、同时导出 Excel。
- **多通道降级**：raw → GitHub contents API → git blob API（base64），并在状态行显示降级链。

## 四、涉及文件

- `app/database.py`：6 张新表与 schema v4 迁移；标签读写层；字段定义/取值层；图集层；
  三类列表框数据源解析；`entry_snapshot`；回收站批量入站与清空回收站的图集释放；`_touch_entry_updated_at`。
- `app/incremental_backup.py`：变更包补 `field_defs`；载荷已含标签/自定义字段/图集。

- `app/parser/hierarchy_import.py`（新增）：四层结构化、选表、质量自检、批量合并、5-d 三项。

- `app/ui/import_wizard_dialog.py`（改造）：三选源 + 网址抓取 + 选表 + 高级头 + 质量自检 + 先存后导 + 5-d。
- `app/ui/github_batch_dialog.py`（新增）：GitHub 目录文件多选与限额。
- `app/ui/field_defs_diff_dialog.py`、`app/ui/settings_dialog.py`：字段差异确认；关于页说明。

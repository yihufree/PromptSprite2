## 1. PromptSprite 是什么？能做什么？

### 1.1 一句话版

**PromptSprite（提示精灵）是一个装在你自己电脑上的"AI 提示词图书馆"**：把几千条到处乱放的提示词，整整齐齐地分类放好；想用的时候，一搜一点就能复制走。

### 1.2 说人话版

如果你平时用 AI 画画、写东西，会攒下很多"好用的指令文本"（比如某个画风的中文 / 英文提示词）。以前它们可能散落在记事本、Excel、微信聊天记录里，找起来非常痛苦。

PromptSprite 就是专门管这些东西的小工具。**所有数据都存在你自己的电脑里，默认不上传、不联网、不收集任何信息。**

### 1.3 它能做什么（一览表）

| 它能做什么 | 对你有啥用 |
|---|---|
| **五级分类书架**：项目类别 → 根目录 → 一级分类 → 二级分类 → 条目 | 2000 条也整整齐齐，不会乱 |
| **鼠标划过就选中**（不用点） | 快速翻分类时不累手 |
| **全局搜索**（搜所有文字，含标签） | 记得一个词就能找到 |
| **一键复制**：复制全部 / 只要中文 / 只要英文 | 不用手动挑，直接粘到 AI 里 |
| **10 个固定字段 + 自定义字段** | 你想多记什么就多加一栏 |
| **标签体系**（标签云 / 列表 / 组合筛选） | 按"画风""用途"横着找，不受分类限制 |
| **智能推荐标签 + 批量自动打标** | 2500 条不用一条条手动打标签 |
| **条目图集**（封面 + 多张图） | 图也一起管起来 |
| **导入导出**：JSON / Excel / Markdown / HTML | 换工具、给别人、备份都方便 |
| **每日变更包**（可换机合并） | 公司改的，回家也能同步 |
| **自动备份 + 导入前快照 + 回收站** | 删错了、导错了都能救回来 |
| **全局热键 `Ctrl+Shift+P`** | 任何时候按一下就跳到软件 |
| **完全离线**（只有你主动抓网页时才联网） | 隐私安全 |

### 1.4 哪些事它不做

- 不会帮你生成提示词（它不是 AI）；
- 不会自动爬网上所有资源（只有你主动给网址它才去读那一个）；
- 不会上传、不会云同步（换机靠"变更包"或复制 `data` 文件夹）。

## 3. 两种使用方式（选一个就行）

### 3.1 方式一：用打包好的 EXE（**推荐给普通用户**）

1. 从 [GitHub Releases](https://github.com/yihufree/PromptSprite/releases) 下载最新 EXE，文件名形如：
   `PromptSprite_<打包日期YYMMDD>_V2.3.0.exe`（**数字是打包日期，后面是版本号**，例如已发布的 `PromptSprite_260916_V2.1.0.exe`）。
   
   > ℹ️ **2026-09-22 起版本号为 V2.3.0**（库结构仍 schema v5 / 导出仍 JSON v6）。**V2.3.0 尚未打包发布**，Releases 上**最新可下载的产物以 Releases 页面标注为准**；如需最新能力，请用源码态运行或自行 `python build.py` 打包。
2. **把它放到一个你记得住、且不会被误删的文件夹**，例如：
   `D:\我的软件\PromptSprite\`
   
   > ⚠️ **千万不要放在"下载"文件夹或桌面**——清理下载/桌面时容易连数据一起删掉。
3. **双击运行**。第一次运行会自动在旁边创建 `data` 文件夹（这就是你的全部数据）。
4. 等几秒钟（第一次要建库），主界面就出来了。

**优点**：不用装任何东西，双击就用。
**注意**：Windows 首次运行可能弹"Windows 已保护你的电脑"——点"更多信息"→"仍要运行"即可（因为是个人开发者、没有买代码签名证书）。

### 3.2 方式二：从源码运行（**给开发者 / 爱折腾的人**）

需要先装 [Python 3.12](https://www.python.org/downloads/)（安装时记得勾选 **Add Python to PATH**）。

打开 PowerShell，依次执行：

```powershell
# 1. 下载源码
git clone https://github.com/yihufree/PromptSprite.git
cd PromptSprite

# 2. 建立虚拟环境（推荐，避免污染系统 Python）
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. 安装依赖（只有 6 个）
pip install -r requirements.txt

# 4. 启动（下面三种任选一种，效果一样）
python app/main.py            # 直接运行主文件（推荐）
python run.py                 # 用根目录的启动器
python -m app.main --smoke    # 冒烟测试：启动 5 秒后自动退出
```

**依赖清单**（`requirements.txt`）：

| 依赖 | 用途 |
|---|---|
| `customtkinter` | 界面框架 |
| `Pillow` | 图片处理（图集、缩略图、生成图标） |
| `pyperclip` | 复制到剪贴板 |
| `openpyxl` | Excel 导入导出 |
| `keyboard` | 全局热键 `Ctrl+Shift+P` |
| `pystray` | 系统托盘图标 |

### 3.3 自己打包成 EXE

如果你改了代码想自己打包：

```powershell

```

产物在 `dist\` 下，自动命名 `PromptSprite_<日期YYMMDD>_V<版本号>.exe`。

## 4. `data` 文件夹是什么？（**先看懂再动手**）

**这是全软件最重要的一件事：你的所有数据都在这个文件夹里。**

### 4.1 它在哪

| 你怎么用的 | `data` 在哪 |
|---|---|
| 用打包的 EXE | **和 EXE 在同一个文件夹里**（例如 `D:\我的软件\PromptSprite\data\`） |
| 从源码运行 | 项目根目录下（`PromptSprite\data\`） |

### 4.2 里面有什么

```
data/
├── prompts.db                       ← 【最重要】你的全部数据（一个文件装下所有条目、分类、标签）
├── images/                          ← 条目里加的图片（本地图）
└── backup/
    ├── prompts_2026-09-17_....db    ← 每次启动自动生成的完整备份（按天去重）
    ├── prompts_preimport_....db     ← 导入数据前的"快照"（后悔药）
    ├── prompts_pretag_....db        ← 批量打标前的"快照"（后悔药）
    ├── tagging/打标批次_....json    ← 批量打标的记录（可精确撤销）
    └── incremental/
        └── 变更包_电脑名_2026-09-17_add_3_del_0.json   ← 每日变更包（可换机同步）
```

### 4.3 三条铁律

1. **换电脑 / 换位置 → 把整个 `data` 文件夹复制过去就行。** 不用装什么数据库。
2. **备份 = 复制 `data` 文件夹**（或只用 `data\prompts.db` 一个文件也能救急）。建议每周复制一次到 U 盘 / 网盘。
3. **不要在软件运行时手动改 / 删 `data` 里的文件**。要清理，请在软件里操作，或用软件的"设置 → 数据与备份"。

## 5. 第一次启动会发生什么

按顺序自动完成，你只需要等：

| 顺序 | 发生什么 | 你会看到 |
|---|---|---|
| 1 | 检查 `data\prompts.db` 是否存在 | — |
| 2 | **不存在** → 从软件内部复制一份"内置完整库"（含 2500+ 条示例提示词与 620+ 个预置标签）；**已存在** → 绝不覆盖 | — |
| 3 | 建立/升级数据库结构（老库自动迁移） | 可能需要几秒 |
| 4 | **自动全量备份**（把当前库复制到 `data\backup\`） | 状态栏短暂提示 |
| 5 | 注册全局热键 `Ctrl+Shift+P`、创建系统托盘图标 | 托盘出现小图标 |
| 6 | 打开主界面 | 见第 6 章 |

> **小提示**：首次启动后，条目区可能显示"共 2556 条（已显示前 50 条）"——这是**性能设计**（一次只画 50 条，避免卡顿），点「▼ 显示更多」可继续加载。

### 6.1 顶部工具栏（从左到右，11 个，逐个说）

| 顺序 | 按钮 | 点它会怎样 | 什么时候用 |
|---|---|---|---|
| 1 | **🔒 锁定** | 进入"锁定状态"：所有会改数据的按钮（保存 / 删除 / 导入 / 移动…）**全部变灰** | 只想看看、怕误碰时 |
| 2 | **🗂 目录隐藏 / 🗂 目录显示** | 打开一个对话框，勾选要隐藏的分类列（可连续隐藏 0~4 列）；**两态文案**：显示着就是"目录隐藏"，藏着就是"目录显示"。对话框里还有"全部隐藏 / 全部显示" | 屏幕小、想把位置让给条目和详情时 |
| 3 | **📂 无类条目** | 只显示"没归到任何分类"的条目 | 检查有没有漏分类的 |
| 4 | **🏷 无标条目** | 只显示"没有任何标签"的条目 | 想补标签时 |
| 5 | **⭐ 常用** | 只显示你收藏（☆）过的条目 | 天天用的那几条 |
| 6 | **🏷 标签** | 打开**标签页面**（标签云 / 列表 / 热点词 / 词表 / 无标条目） | 按标签找东西、管词表 |
| 7 | **✚ 新建** | 打开"快速新建"窗口（划过分类就选中，连续录入） | 批量录入 |
| 8 | **⇩ 导入** | 弹出菜单：从文件导入 / 从网址获取（结构化向导）/ 导入变更包 / 数据比对 | 把外面的数据搬进来 |
| 9 | **⇧ 导出** | 弹出菜单：导出 JSON / Excel / Markdown / HTML / 变更包 | 备份、给别人、浏览 |
| 10 | **⚙ 设置** | 打开设置对话框（6 页） | 改配置 |
| 11 | **搜索框 🔍** | 输入后**停顿约 1.5 秒**自动搜；点 🔍 或按回车**立即搜** | 找条目 |

> **为什么搜索要等 1.5 秒？** 这是**故意的**——如果每敲一个字就整库查一遍，输入长句子会非常卡。想立刻出结果就按回车或点 🔍。

### 6.2 左侧书架（五级）

- **项目类别**（第 1 列）→ **根目录**（第 2 列）→ **一级分类**（第 3 列）→ **二级分类**（第 4 列）→ **条目**（右侧）。
- **鼠标划过某个按钮约 0.2 秒 = 选中它**，不用点击。
- 选中的那一整条链路会**变深蓝色高亮**，一眼看出你在哪。
- **重要特性**：**每一级分类都可以直接挂条目**。也就是说，你可以在"根目录"这一层就放条目，不必非得建到二级分类。

### 6.3 右侧详情区

- 上半部分是**字段**：① 名称、② 介绍、③ 溯源、④ 核心特征、⑤ 应用场景、⑥ 代表作、⑦ 代表高清配图、⑧ 中文提示词、⑨ 英文提示词、⑩ 图像获取方案（详见[第 26 章](#26-附录-字段都是什么)）。
- 中间是**命令条**：☆ 收藏 · ➜ 移动到 · ↔ 关联到 · ⧉ 复制到 · ✏️ 编辑 / 👁 浏览 · 💾 保存 · 重置 · 复制全部 / 中文 / 英文。
- 底部是**常驻栏**：🗂（一键显隐目录）· 🏷（打开标签页面）· 🕒 新增历史 · ♻ 删除历史 / 回收站 · 🗑 删除当前条目。

**✏️ 编辑 / 👁 浏览（强烈建议用起来）**：
- 👁 **浏览**态：字段只能看、能选中复制，**改不了**——防止手滑改坏；
- ✏️ **编辑**态：正常编辑、可保存。
- 浏览态下"保存 / 删除 / 移动 / 关联 / 复制"等按钮会自动变灰。

### 6.4 两个好用的"浮层"

| 浮层 | 怎么出 | 有什么用 |
|---|---|---|
| **条目名称一览** | 鼠标在条目区停约 0.5 秒 | 一次看全当前分类下所有条目名；**鼠标可以移进浮层里滚动** |
| **字段浮动提示窗口** | 鼠标停在某个字段的文本框上 | 长文本看得全；随文本框同步滚动；可在设置里用总开关关闭 |

## 7. 设置对话框 6 页逐项说明

点 **⚙ 设置** 打开。左边是 6 个页签，右边是对应设置。

## 8. 基本操作：新增 / 编辑 / 复制 / 删除

### 8.1 新增一条提示词（两种入口）

**入口 A：随便在哪儿新建（最常用）**

1. 点工具栏 **✚ 新建**（或详情区底部、条目区的绿色"＋ 新增条目"）；
2. 出现"快速新建"窗口：**左侧 4 列分类，鼠标划过就选中**（0.2 秒）；
3. 划过二级分类（或没有下级的一级分类）→ 状态行显示"✔ 已锁定：xxx"，**光标自动跳到 ① 风格名称**；
4. 填 ① 名称（必填），需要就填其它字段；
5. 想让它不归任何分类 → 点左上角 **📂 归入未分类**；
6. 点 **💾 保存** → 窗口**不会关闭**，表单会被清空，可以**连续录下一条**。

**入口 B：就在当前分类下新建**

1. 在左侧书架选好你要放的分类；
2. 点条目区的绿色 **"＋ 新增条目"**；
3. 在右侧详情区填内容 → **💾 保存**。

> **小技巧：标签可以自动推荐。** 在"快速新建"里，填完 ① 名称后**按回车或点到别处**，软件会自动推荐 1~3 个标签（来源会显示在状态行）。不想要的点标签上的 `×` 去掉即可。

### 8.2 查看与编辑

1. 在条目区点一条 → 右侧详情区显示它的全部内容；
2. 点 **✏️ 编辑**（如果当前是浏览态）；
3. 改字段 → 点 **💾 保存**；
4. 改错了想撤销当前这次编辑 → 点 **重置**（恢复到上次保存的状态）；
5. 文本框里还能用 **Ctrl+Z 撤销 / Ctrl+Y 重做**。

### 8.3 复制提示词

详情区命令条上有三个按钮：

| 按钮 | 复制什么 | 典型用途 |
|---|---|---|
| **复制全部** | 中文 + 英文 + 其它内容 | 一次拿全 |
| **复制中文** | 只复制 ⑧ 中文提示词 | 中文 AI 直接用 |
| **复制英文** | 只复制 ⑨ 英文提示词 | 英文 AI / 绘画工具直接用 |

复制后会弹出小提示"已复制"，直接去 AI 里 Ctrl+V 粘贴即可。

### 8.4 收藏（⭐ 常用）

- 详情区命令条最左的 **☆ 收藏** → 点亮变成 ★；
- 之后点工具栏 **⭐ 常用** 就能只看收藏的条目。

### 8.5 一条条目放在多个地方：关联到 / 复制到 / 移动到

| 操作 | 含义 | 什么时候用 |
|---|---|---|
| **↔ 关联到** | 同一条条目出现在多个分类里，**在任意一处改了，其他几处同步变**；删掉一处不会删掉条目本身 | "这条既属于风格 A 也属于风格 B" |
| **⧉ 复制到** | 造一个**独立副本**放到别的分类，之后各改各的、互不影响 | 想改出一版变体 |
| **➜ 移动到** | 把条目搬走；可勾选 **"整体转移"**（清空它在其它分类的关联位置） | 分类放错了 |

**详情区"🧭 位置"面包屑**：详情区上方会显示这条条目**当前挂在哪些位置**（例如 `网上资源收集 › 视觉风格分类 › 油画 › 印象派`）。每个位置旁边有解除按钮，可以逐处解除。

### 8.6 删除一条提示词（**会先进回收站，别怕**）

1. 选中条目 → 点详情区底部的 **🗑 删除当前条目**；
2. 弹窗二次确认 → 确定；
3. 条目**进入回收站**（不是真的删掉），图片也一起保留。

**怎么救回来**：点底部 **♻ 删除历史 / 回收站** → 找到那条 → 点恢复 → 内容、收藏状态、多个位置**全部原样回来**。

**怎么真正删掉**：在回收站里点"彻底删除"，或点"清空回收站"（此时图片文件才会真正释放）。

## 9. 分类管理（书架怎么整理）

### 9.1 新增分类

- 每一列顶部都有 **"➕ 新增一级分类"** 之类的按钮（**初始是灰的**，先选中上一级再变亮）；
- 点它 → 输入名称 → 确定。
- 在"快速新建"窗口里也能新增（同样在每列顶部）。

### 9.2 复制 / 移动分类

对根目录 / 一级 / 二级分类都可以：

- **复制到…**：在别处造一份，**包括里面的子分类和条目**；
- **移动到…**：搬走，**条目不会丢**。

**软件会自动处理重名和层级前缀**：
- 往下挪时自动加前缀（`A` → `A.C`）；
- 往上挪时自动去掉前缀；
- 碰见重名自动加序号；
- 碰到共享分类自动复制。

### 9.3 删除分类（三级保护，不容易误删）

| 情况 | 会发生什么 |
|---|---|
| 有子分类 | 先弹提示"请先处理下级"，**不让删** |
| 没有子分类 | 只**解除**挂在这个分类下的条目的位置（**条目本身不删**，会回到"无类条目"） |
| 要**连子树整棵删掉** | 必须**手工输入确认短语** → 再点二次确认 → 才会删（这是最高级别保护） |

### 9.4 批量删除本分支全部数据（**右键菜单，六道关卡**）——2026-09-22 新增

**在哪**：在左侧导航的「**项目类别 / 根目录 / 一级分类 / 二级分类**」任一列上**右键** → 选「**🧹 批量删除本分支全部数据…**」。

**六道关卡（顺序固定，任何一步点"取消"都立即中止，且不写任何数据）**：

| 关卡 | 你会看到 | 要做什么 |
|---|---|---|
| ① **影响范围统计** | 弹窗列出：将删除的**分类记录数** / 需**解除关联的共享分类数** / 删除的**根目录数** / 处置**本体的条目数** / **仅解除位置关联的条目数** | 看清数字 → 确认后进入下一步 |
| ② **确认短语** | 要求**手工输入**短语「**删除全部下级内容**」 | 逐字输入（不能图省事跳过） |
| ③ **删除方式** | 三选一：**软删除**（条目移入回收站，可从「删除历史 / 回收站」恢复，**推荐**）/ **硬删除**（条目彻底删除，**无法从回收站恢复**，只能靠备份或导出文档恢复）/ 取消 | 想清楚再选 |
| ④ **项目类别专用关卡** | **仅当删除的是「项目类别」时**出现：先**手工输入该项目类别的完整名称**，再输入**专用口令**（公开默认口令 **123456**） | 逐项输入 |
| ⑤ **自动双重备份** | 自动生成：全量库快照 `data/backup/prompts_predel_<时间戳>.db` + 待删分支全部数据 `data/backup/prompts_branch_<分支名>_<时间戳>.json` | 什么都不用做；**任一备份失败会直接中止删除，不写任何数据** |
| ⑥ **执行删除** | 执行删除，并**自动刷新**左侧导航与条目区 | 完成 |

**删除口径（很重要，决定了"会不会误删"）**：

- **共享分类只解除关联、不删除记录**：被**其他根目录共享**的一级分类，只解除它与本分支的关联，**其他根目录仍然可以正常访问它**；只有**仅属于本分支**的分类，才连同它的子树一起删除。
- **条目本体看"位置"**：一条条目只有在它的**全部位置**都落在本次删除范围内时，才删除**条目本体**；只要还有**任何一个位置在范围之外**，就**只删除范围内的位置关联，条目本体保留**。
- **软删除可恢复**：选"软删除"时，被删条目按回收站机制保存，可从「删除历史 / 回收站」恢复。

> ⚠️ 口令 `123456` 只是**多一道手工关卡**，**不构成安全防护**（见第 22 章第 20 条）；真正的数据兜底是第 ⑤ 步的**双重自动备份**与**软删除进回收站**。

## 10. 标签系统（重点）

### 10.1 标签是什么？和分类有什么区别？

- **分类**是**竖着**的（一条只在一个地方）：像书架的层。
- **标签**是**横着**的（一条可以有多个）：像便利贴。
- 举例：一条"赛博朋克夜景人像"可以分类在 `图像 › 人物 › 人像`，同时打上标签 `赛博朋克`、`夜景`、`电影感`。
- 于是你既可以"按分类找"，也可以"按标签找"——**两个维度交叉，找东西快得多**。

### 10.2 在详情区打标签

1. 选中条目 → 详情区找到 **🏷 标签** 区块；
2. 在输入框里打字：**会自动补全**你已经用过的标签；按回车即添加；
3. 不想让它自动补全？直接把词打完按回车，就是**新建一个标签**；
4. 加的标签会显示成彩色小圆片（chip），点上面的 **×** 就移除；
5. 别忘点 **💾 保存**。

区块里还有两个按钮：

| 按钮 | 作用 |
|---|---|
| **✨ 推荐标签** | 软件按内容自动推荐 1~3 个标签，并**直接把结果加上去**（默认全选，不想要的点 × 去掉） |
| **📋 选择…** | 从"你用过的标签 ∪ 词表 ∪ 热点词"里**勾选**，也可以现场新建 |

### 10.3 标签页面（工具栏 🏷 标签）

打开后有 **4 个页签**：

| 页签 | 内容 | 能干什么 |
|---|---|---|
| **标签** | 你所有用过的标签 | 两种呈现：**☁ 标签云**（字越大用得越多）/ **列表 + 计数**；选多个标签后可用 **且（都要有）/ 或（有其一即可）** 组合筛选；可**重命名 / 合并 / 删除 / 清理未使用**；可搜索；可分页（前 50 / 100 / 200 / 500 / 全部） |
| **热点词** | 热点词清单 | 逐条添加 / 文本导入 / 从来源网址抓取 |
| **词表** | 标签规则库的结构预览 | 导出 / 导入（替换）/ **增量导入（只增不删）** / 恢复出厂 |
| **无标签条目** | 底部显示 `⚠ 无标签条目（N）` | 直接跳到"没打标签"的条目列表 |

> **标签页面和左侧四级目录是互斥的**：打开标签页面时，左侧书架会收起；关掉标签页面就回到你原来待的地方。

### 10.4 用 `#标签` 搜索

在搜索框里输入：

| 输入 | 结果 |
|---|---|
| `#电影感` | 所有带"电影感"标签的条目 |
| `#无标签` | 所有**没有标签**的条目（英文别名 `#none`，两个一样） |
| `#无标签 夜景` | 没有标签**并且**内容里有"夜景"的条目 |

## 11. 智能标签与批量自动打标（重点）

### 11.1 为什么一打开就有标签？

打包版内置的 2500+ 条示例数据**已经预先打好标签了**（**2026-09-18 重打后实测 593 个标签 / 6574 条标签关联**，**以你实际库为准**；重打原因：出厂词表当天上午升级为 699 标签版，预置标签随之按新词表重生成——此前为 592 / 6536）。
所以你一打开标签页面就能看到东西，不用从零开始打标签。

> 如果你是**老用户**：你的库是你自己的数据，本来没有标签。想批量补上 → 用下面的"批量自动打标"。

### 11.2 软件怎么决定给什么标签？（原理，一句话）

按**你设定的「推荐策略与顺序」**（设置 → 标签与词表）依次尝试，**每个来源都"尽力推荐"**，
最后**按顺序取前 N 个**（默认 3）：

1. **条目自己写明的标签**（内容里有「标签：xxx」）——**恒为最高优先、不可关闭**；
2. 其余来源按你排的顺序执行：**热点词** / **领域+词表匹配** / **字段取词** / 扩展接口（预留）。
   把某个来源排在前面，它的标签就更可能进最终结果（**来源之间不再互相扣减名额**，2026-09-18 起）。

**「字段取词」具体怎么取**（2026-09-18 优化后）：
- 从 ① 名称 + ⑧ 中文提示词 + ⑨ 英文提示词 切词（提示词按**逗号 / 顿号 / 分号**切开，像 `film grain`
  这样的英文短语会保持完整；`film-grain`、`film_grain` 也会归一成 `film grain`）；
- **命中词表 / 热点词**的（含 `high contrast` 这类**两词短语**与 `portraits` 这类**复/单数**）→
  换成词表里的**规范标签名**（例如 `low angle` → 「低角度」）；
- **词表外的高质量新词** → 直接以原文作为标签（来源标注「取词（新词）」）：
  中文 **2~6 字**、英文**两词短语**；**单个英文单词不收**；
- **提示词样板词与占位符一律排除**（`masterpiece` / `8K` / `HDR` / `aspect ratio` / `BRAND NAME` /
  `headline text` / `生成图片` …），它们既不会成为标签，也不会进「自动取词词库」；
- **尽力而为**：正常情况下「有就推荐、没有就算了」（0~3 个都允许）；
  **有来源自带标签（「标签：…」）时也不跳过取词**——照常产出，只是排在显式标签之后；
- **兜底取词（保证不空白）**：**当「热点词」与「领域+词表匹配」两个来源都为 0 时**，
  字段取词自动切到**兜底闸门**（中文 2~12 字、英文 1~3 个单词）重算一次并追加到队尾
  ⇒ **保证字段取词至少推荐 1 个**（来源提示会写「兜底取词」）。

最终每条例目 **1~3 个标签**，且每个维度（如"风格""用途"）**最多 1 个**，避免标签刷屏。

### 11.3 批量智能自动打标（**关键功能**）

**入口**（两个都行）：
- 设置 → **标签与词表** → **🤖 批量打标…**；
- 标签页面底部的"🤖 批量打标…"。

**它能做什么**：

| 选项 | 可选值 | 说明 |
|---|---|---|
| 目标条目 | **仅无标签的条目** / **全部条目** | 想补标签选前者（**不会动你已经手工打好的标签**） |
| 范围 | 全部 / 指定根目录（含子树）/ **当前列表** | "当前列表"＝你当前屏幕上筛出来的那批（比如"无标签条目列表"） |
| 数量上限 | 任意数字 | 先小批量试水，比如先打 20 条 |
| 每条例目标签数 | 1 / 2 / 3 | 建议 3 |
| 标签重点范围 | 按维度勾选 | 只要"风格"就只勾风格 |
| 写入策略 | **追加** / 覆盖 | 建议"追加" |

**四重安全保障（软件强制，你改不了）**：

1. **必须先"预演"**——预演是只读的，会告诉你要打多少条、每条会打上什么标签（给样例看）。**没预演点不动"执行"**；
2. **执行前自动备份**——备份失败就直接中止，绝不冒险；
3. **二次确认**——弹窗会如实告诉你"这些改动会进入今天的变更包"；
4. **执行后可"精确撤销"**——只回退**这一次**打标，不碰你后来做的其它修改。

**怎么撤销**：标签页面 / 设置里打开 **批量打标历史批次** → 找到那一次 → 点撤销。

> **记不住也没关系**：软件的默认口径是"安全优先"——宁可多问你两遍，也不偷偷改你的数据。

## 12. 词表 / 热点词 / 自动取词词库

### 12.1 词表（标签规则库）

**是什么**：一份"什么词→算什么标签"的规则表。软件靠它把内容里的词识别成标签。

**出厂词表结构**（**2026-09-18 午后起升级为 809 个标签版**）：
- **通用骨架**（领域 / 用途，29 个标签）；
- **领域维度包**（21 个）：视觉 54 / 编程 64 / AI生成 41 / AI大模型应用 32 / 电影 41 / 视频编辑 41 /
  音频 24 / 音乐 34 / 绘画 34 / 艺术 51 / 动画 27 / 图形处理 36 / 视频类型与平台 23 / 摄影摄像 34 /
  3D建模渲染 32 / 设计 35 / 软件工具 24 / AI写作 26 / 电视 19 / **作者专用 93** / **用户词表 15**；
- 合计 **809 个标签**。
- （历史：同日上午一版为 699 个标签 / 19 个领域包；V2.1.0 时为 135 个标签＝通用骨架 18 + 视觉 54 / 文学 39 / 编程 24 三个领域包。）

> **换出厂词表后，我原来库里的词表会跟着变吗？** 不会。出厂词表只在两种情况生效：
> ① 全新安装（首次建库）；② 你点「↺ 恢复出厂…」。已在用的库以库里的词表为准（点一次「↺ 恢复出厂…」即切到新出厂词表，改前会自动备份）。

**在哪管**：标签页面第 3 个页签 **词表**，或 设置 → 标签与词表 → **词表管理…**。

| 按钮 | 作用 |
|---|---|
| **⬆ 导出词表…** | 导出一个 JSON 文件，可以用记事本 / VSCode 编辑 |
| **⬇ 导入（替换）…** | 把你的 JSON 导进来，**整份替换**现有词表（**导入前会先校验**，不合法直接拒绝；并**自动备份当前词表**） |
| **➕ 增量导入…** | **只增不删**：把你的 JSON **并入**现有词表——同名标签的匹配词并集去重，新标签 / 新维度 / 新领域包自动新增，**现有内容一个不删**（2026-09-17 新增） |
| **↺ 恢复出厂…** | 回到软件默认词表 |

**两个"导入"怎么选？**

| 你的想法 | 用哪个 |
|---|---|
| 我只想**再加几个词/几个标签**，原有的一定要留住 | **➕ 增量导入…** —— 不必再"导出→手工把新词并进整份文件→导入" |
| 我要让词表**完全照这份文件来**（多余的要删掉） | **⬇ 导入（替换）…** |

> 增量导入与"导入（替换）"一样安全：**先校验**（不合法直接拒绝、不写库）→ 弹确认框写明"将新增标签 X 个 / 匹配词 Y 个，现有 N 个标签全部保留" → 写库前自动备份当前词表。
> 同一个文件重复增量导入是**幂等**的：第二次会提示"无可新增内容"，不写库、也不产生多余备份。

**想加一个"学术"大类？** 不用改代码：
1. 先**导出词表**；
2. 用记事本打开 JSON，在里面按已有领域包的**同样格式**加一个"学术"包（放进 `domains` 里）；
3. **导入**（想保留现有内容就用 **➕ 增量导入**）→ 完成。

### 12.2 热点词表

**是什么**：一份"我特别关注的词"清单。打标时会优先看它。
**和词表的区别**：词表是"完整的规则库"，热点词是"临时加急、优先级最高的几个词"。

**在哪管**：标签页面第 2 个页签 **热点词**，或 设置 → 标签与词表 → **热点词管理…**。

**三种录入方式**：
1. **逐条添加**：输入框打一个词 → 回车；
2. **文本导入**：粘贴一段文字，或选 `.txt / .csv / .md / .json` 文件；
3. **从来源网址抓取**：填一个页面地址 → 点抓取 → **先预览** → 确认后**并集追加**（抓失败不影响已有词）。

> 热点词初始为空，这是正常的。

### 12.3 智能自动取词词库（**让软件越用越懂你**）

**它解决什么问题**：打标"取词"的时候，有些**好词不在你的词表里**。以前这些词每次都要人工判断、然后就丢了。现在软件会把它们**自动记下来**。

**怎么记**：每个词记两项：
- **命中次数**（出现多少次）；
- **不同条目数**（出现在多少条不同的条目里）——**这个才是判断依据**，同一条条目里重复出现只算 1 次。

**达到阈值会怎样**（阈值都能改）：

| 达到 | 会发生什么 |
|---|---|
| **热点阈值**（默认 3 个不同条目） | **自动写进热点词表** → 下次打标就直接命中它 |
| **词表阈值**（默认 5 个不同条目） | **只提示你审核**，**不会自动改你的词表**。你需要在管理对话框里**勾选 → 选"领域 → 维度 → 标签名" → 确认**，它才写进词表 |

**管理对话框在哪**：设置 → 标签与词表 → **🧠 自动取词词库…**

**里面能干什么**：
- 看列表（词 / 不同条目数 / 命中次数 / 来源字段 / 末现时间 / 状态）；
- 按状态筛选（全部 / 仅候选中 / 仅已达词表阈值 / 已升热点词 / 已入词表 / 已忽略）；
- 搜索；
- 全选可见 / 全不选；
- 批量操作：🔥 加入热点词表 / 📚 加入词表标签… / 🚫 忽略 / 🗑 从词库删除 / ⚡ 一键处理全部达标项；
- 🧹 清空词库（已加入热点词 / 词表的词**不受影响**）；
- 设置：采集范围是否含自动推荐（T2）、词库上限（默认 2000）、两个阈值。

**默认行为（重要）**：
- 只采集**你主动点「✨ 推荐标签」**这一路径的词；**输入停顿后自动推荐**产生的词默认不计入（可在对话框里放开）；
- **批量打标 / 离线打标不采集**（保证批量操作不会污染你的词库）。

### 12.4 「取词用于批量打标」开关

- **两个入口、同一个设置**：设置 → 标签与词表 页；或 批量打标对话框里的「⑦ 取词用于批量打标」。**在任一处改动，另一处同步**。
- **默认关闭**：关着的时候，批量打标只走"显式标签 → 分类名映射 → 词表匹配"，和内置数据的口径一致。
- **打开后会怎样**：批量打标也会启用"字段取词"，可能写入一些新标签。**建议先小批量预演确认**。
- 在批量打标对话框里改这个开关，会**立即作废当前预演**（防止你拿旧口径去执行）。

## 14. 条目图集（封面 + 多图）

### 14.1 两种图、两个来源

- **封面**：一条的"代表图"；
- **图集**：一条可以放多张图。

来源两种：
- **本地图**：从你电脑上选文件（会复制进 `data\images\`，所以**原文件删了也不影响**）；
- **外链图**：直接填网址（不下载，省流量、保隐私）。

### 14.2 把外链图"下载到本地"

图集里每条外链图旁边有"下载到本地"。点它就把图存进 `data\images\` 并改为本地引用。
**下载失败**时不会破坏什么：会**保持外链**，并把原来的来源网址留着。

### 14.3 新建条目时加的图不会白留

新建时选的图会先"暂存"，**只有你点保存成功之后**才会真正复制进 `data\images\`。如果你取消不保存，不会留下一堆没用的图片文件。

### 14.4 图片随数据一起走

- 图片存在 `data\images\`，**整个 `data` 文件夹复制走，图也一起走**；
- 删除条目时**图先留着**（因为要能恢复）；只有"彻底删除 / 清空回收站"时才真正删图片。

## 15. 把详情区排成你习惯的样子（排序 / 隐藏 / 折叠 / 外观）

> 这一章讲的是 2026-09-16 新增的能力——**详情区从此由你说了算**。

### 15.1 区块自由排序（① 名称以外，全都能调）

**在哪**：⚙ 设置 → **字段** → **🔧 字段管理…** → 每行右侧的 **↑ / ↓**。

**能调什么**：**除 ① 名称外的所有区块都在同一个顺序里**，可以自由上下移动，**允许跨组**：

| 区块 | 说明 |
|---|---|
| 🏷 标签 / 🧭 位置 / 🕒 时间 | **虚拟区块**——不是条目的真实字段，只是详情区里的一块显示区。**不能改名、不能删，但可以排序、可以隐藏** |
| ② 介绍 ~ ⑩ 图像获取方案 | 内置 9 项（① 名称固定在第一，不参与排序） |
| 你的自定义字段 | 和上面一起排在同一个顺序里，也能跨组插 |

**举个例子：把「🏷 标签」挪到「② 介绍」后面**
1. 设置 → 字段 → 🔧 字段管理…；
2. 找到 `_tags` 那一行，点它右边的 **↑**，一直点到它在 `intro` 后面（**每点一次即时生效**）；
3. 点「确定」→ 详情区立刻按新顺序重排。

**要点**：
- 顺序是**全局设置**：所有条目共用一套顺序；**编辑态和浏览态完全一致**；
- 排序**只改显示顺序**，不改任何数据；
- 这个顺序**不会跟着数据包换机**（换台电脑重新调一次，或用同一台机的备份恢复会带回）。

### 15.2 区块隐藏 / 显示

**在哪**：⚙ 设置 → **字段** → **🔧 字段管理…**

| 控件 | 位置 | 作用 |
|---|---|---|
| **隐藏 / 显示** | 每个字段行的 ↑↓ **右边** | 点"隐藏"→ 详情区不再显示这块；按钮变成"显示"，再点就恢复 |
| **全部隐藏 / 全部显示** | 字段列表**左下角**（"显示已归档字段"勾选框右边） | 一键把所有可隐藏区块设为隐藏 / 显示 |

**三条必须知道的规则**：

1. **① 名称不能隐藏**。它那一行**没有**这个按钮，"全部隐藏"也不会隐藏它——详情区永远至少有 ① 名称；
2. **"手动隐藏"是硬隐藏**。不管"详情字段显示"设成 自动 / 全部 / 精简，被隐藏的区块**都不显示**；
   详情区头部的「⏵ 显示全部字段」按钮**也不能**把它显示出来——**只能**回字段管理里改回"显示"。
   但只要你隐藏过东西，详情区头部状态行会提示「**（另有 N 项已隐藏，可在「字段管理」中恢复）**」，不会让你以为数据丢了；
3. **隐藏 ≠ 删除**。隐藏**只影响详情区的显示**：字段定义、已经填好的内容、导出、搜索、变更包统统不受影响。
   隐藏后这块**不占位置，下面的内容自动上移**；改回"显示"内容原样回来。
   （想"彻底从列表里去掉一个自定义字段"请用「**删除**」＝归档。）

**哪些受影响、哪些不受影响**：

| 场景 | 受影响吗 |
|---|---|
| 详情区（编辑态 / 浏览态） | ✅ 隐藏后不显示 |
| 「＋ 新增条目」表单 | ❌ **不受影响**——新增时**始终显示全部区块**，保证什么都能填 |
| 导出 JSON / Excel / 变更包 | ❌ 不受影响，内容照常导出 |
| 全局搜索（含 `#标签`） | ❌ 不受影响，被隐藏字段的内容照样能搜到 |
| 换机 / 数据包 | ❌ 不受影响——隐藏是"本机显示偏好"，**不写进数据包** |

**举个例子：只想留 ① 名称 + ② 介绍 + 提示词，其他全收起来**
1. 设置 → 字段 → 🔧 字段管理…；
2. 点左下角「**全部隐藏**」→ 提示"已隐藏全部区块（① 名称始终显示，共 N 项）"；
3. 对想留下的 `intro` / `prompt_cn` / `prompt_en` 逐行点「**显示**」；
4. 点「确定」→ 详情区只剩这几块，界面清爽，**内容一条都没少**。

### 15.3 ②~⑦ 各自独立折叠

- 每个字段标题右边都有自己的「**展开 / 收起**」按钮（以前是"②~⑦ 整组一个按钮"）；
- ⑦ 的图片预览区会跟着这个字段一起显示 / 收起；
- 详情区头部的「⏵ 显示全部字段 / ⏸ 精简显示」按钮管的是"**把这些可折叠字段全部展开 / 收回**"，**管不了**上面 15.2 的"手动隐藏"。

### 15.4 外观（字体 / 字号 / 颜色）

⚙ 设置 → **外观** 页，可给 6 类元素分别设置。**留空＝不改**（保持软件默认样式）。建议只调字号。

## 16. 数据安全（**最该读的一章**）

软件给了你**五重**保护。搞懂这五重，你就基本不会丢数据了。

### 16.1 第一重：每次启动自动全量备份

- **什么时候**：每次打开软件时；
- **备份在哪**：`data\backup\prompts_2026-09-17_xxxxxx.db`；
- **按天去重**：同一天开多几次，**只保留最后一份**（不占空间）；
- **保留多少**：默认 **30 份**（可在设置里改）；
- **只清理"标准命名"的备份**：你手动复制的快照（`snapshot_*` 等）**永远不会被自动清理**；
- **失败了怎么办**：状态栏会出现"● 备份失败"的黄色提示。**看到请立刻手工复制一份 `data`。**

### 16.2 第二重：导入前 / 打标前自动快照

| 什么时候 | 生成什么 |
|---|---|
| 导入任何数据之前 | `prompts_preimport_2026-09-17_xxxx.db` |
| 批量打标之前 | `prompts_pretag_2026-09-17_xxxx.db` |

**这两类文件永不自动清理**，是专门的"后悔药"。快照失败 → **软件会直接中止导入/打标**（宁可不动，也不冒险）。

**怎么用后悔药**：关掉软件 → 把 `data\prompts.db` 改名备份 → 把那个 `preimport` 文件复制一份改名为 `prompts.db` → 重新打开软件。

### 16.3 第三重：回收站（删除可恢复）

- 删除条目 = **完整快照进回收站**（含内容、收藏状态、多个位置、图片）；
- 从回收站恢复 = **原样回来**；
- 图片文件在**彻底清除时**才释放。
- **批量删除也走这一重（2026-09-22 新增）**：右键「🧹 批量删除本分支全部数据…」选「**软删除**」时，被删条目同样进回收站、可恢复；无论软删还是硬删，删除前都会**自动做双重备份**（全量库快照 + 待删分支 JSON），**任一备份失败即中止删除**（详见第 9.4 节）。

### 16.4 第四重：变更包导入向导（防"导错就误删"）

导入带删除清单的包时，软件**先预览**（来源电脑、日期、新增/修改/删除各多少条），再让你做**二维选择**：

| 选择 | 选项 |
|---|---|
| ① 包里的新增 / 修改 | 合并 / 不合并 |
| ② 包里的删除清单 | **忽略删除（推荐）** / 正常应用删除（要输入"确认删除"）/ **⑤ 逆向恢复**（要输入"恢复删除"） |

**并且**：因同步而产生的删除，**一律先进回收站**（绝不会"导入即永久删除"）。

### 16.5 第五重：批量打标可精确撤销

见 [11.3](#113-批量智能自动打标关键功能)。撤销**只回退那一次打标**，你后来做的其它修改不受影响。

### 16.6 手动备份（强烈建议养成习惯）

| 频率 | 做法 |
|---|---|
| 每周 | 把整个 `data` 文件夹复制到 U 盘或网盘 |
| 大动作前（大批量导入、批量打标、清理回收站） | 手工复制一份 `prompts.db`，改名为 `snapshot_2026-09-17_动大手术前.db` 放在 `data\backup\` 里 |

## 17. 每日变更包与换机同步

### 17.1 它是什么？什么时候生成？

- **关闭软件时**自动生成，内容是"**今天发生的全部变化**"（新增 / 修改 / 删除 / 空分类）；
- 存在 `data\backup\incremental\`；
- **同一天只会有一份**（再关一次会覆盖当天那份，不会堆一堆）。

### 17.2 文件名怎么读

`变更包_DESKTOP-053MORJ_2026-09-17_add_3_del_0.json`

| 部分 | 含义 |
|---|---|
| `变更包` | 文件类型 |
| `DESKTOP-053MORJ` | **电脑代号**（建议在设置里改成好认的名字） |
| `2026-09-17` | 变更日期 |
| `add_3` | 新增 + 修改合计 3 条 |
| `del_0` | 删除 0 条 |

> **`del_` 数字很大** = 这是一个"纯删除包"（负增量）。软件在导出时会**红字警告**"⚠ 负增量，谨慎分发"。

### 17.3 怎么用它换机 / 给别人

**换机同步（两台电脑都有这个软件）**：

1. 在 A 电脑正常用完 → 关闭软件 → 生成变更包；
2. 把 `data\backup\incremental\变更包_A电脑_2026-09-17_add_3_del_0.json` 拷到 U 盘；
3. 在 B 电脑打开软件 → 点工具栏 **⇩ 导入** → **导入变更包** → 选这个文件；
4. **仔细看预览**（尤其是"删除 N 条"）；
5. 做二维选择（见 [16.4](#164-第四重变更包导入向导防导错就误删)）；
6. 确定 → 完成后**核对一下条目总数**。

**给别人（只要一个文件）**：
点 **⇧ 导出** → 变更包，或直接用整库 JSON（内容更全但文件更大）。

### 17.4 一个真实的"救回来了"的例子（体会一下）

假设 B 电脑上误删了 500 条条目，之后又做了别的编辑。

1. B 电脑关闭软件 → 生成变更包 `变更包_B_2026-09-17_add_3_del_500.json`（**纯删除包**）；
2. A 电脑导入这个包 → 预览看到"删除 500 条"的红字警告；
3. **千万不要**选"正常应用删除"！选 **"忽略删除（推荐）"** → A 电脑数据安然无恙；
4. 反过来，如果 A 电脑**希望**把这 500 条恢复回 B 电脑：先在 A 电脑设置里打开**"变更包携带被删快照"**，重新导出一份带快照的包，到 B 电脑导入时选 **"⑤ 逆向恢复"** → 被删的 500 条**反向加回**。

### 17.5 "携带被删快照"要注意什么？

| 开启的好处 | 开启的代价 |
|---|---|
| 变更包带上被删条目的**完整内容**，可以在别的电脑上"逆向恢复" | ① 文件**体积变大**；② 文件**包含已删除的内容**；③ 可能含你当初**有意删掉**的数据（隐私风险） |

**默认是关的。** 如果这个包要发给别人，**请先想清楚**。

## 18. 数据比对

**这是干什么的**：拿一个**历史备份库**和**当前库**对比，看看差在哪儿。

**怎么用**：
1. 点 **⇩ 导入** → **数据比对…（与备份 \*.db）**；
2. 选一个备份文件（比如上周的 `prompts_2026-09-10_....db`）；
3. 软件会把备份**复制到临时文件后只读打开**（**绝不碰你的主库**）；
4. 看差异概览：项目类别 / 根目录 / 分类 / 条目 各差多少；
5. 看明细列表；
6. 可以**导出 HTML 差异报告**（用浏览器打开，看得更清楚）。

> **注意**：锁定状态下这个功能不可用（因为锁定是"防误操作"状态）。

> 🔎 **2026-09-17 改进：条目"内容已修改"改按稳定 ID 识别**
> 只要备份与当前库里是**同一条**（稳定 ID 相同），即使你**改了名称又改了内容**，也会准确报成「**条目（内容已修改）**」，
> 备注里还会标「**按稳定 ID 配对**」，并从"删除 + 新增"的噪音里消除掉。
> 更早的备份库（还没有稳定 ID）无法这样配对，会自动回到原来的"按名称 + 位置"识别方式，**结果与以前一样**。

## 19. 导入导出（含结构化向导与联网抓取）

### 19.1 支持哪些格式

| 格式 | 导出 | 导入 | 说明 |
|---|---|---|---|
| **JSON**（当前 **v6**） | ✅ | ✅ | **最完整**（含分类路径、字段定义、自定义字段、标签、图集、**稳定 ID 与位置清单**）；兼容 **v2 / v3 / v4 / v5** |
| **Excel**（.xlsx） | ✅ | ✅ | 适合给人看、给人改；导入会自动去重 |
| **Markdown** | ✅ | — | 适合存档、贴笔记 |
| **HTML** | ✅ | — | 适合用浏览器浏览 |
| **变更包**（JSON） | ✅ | ✅ | 每日自动生成；带删除清单，走专门向导 |
| **CSV / TSV / TXT / HTML / MD** | — | ✅ | 通过"结构化向导"导入 |

> **大文件导入会慢**（几千条要建好几千个分类）。软件有进度条，耐心等。**导入前一定会自动快照**。

### 19.2 导出 JSON / Excel

1. 点 **⇧ 导出** → 选格式；
2. 选保存位置 → 确定；
3. 完成后会提示导出了多少条。

> 🆕 **2026-09-22 起：导出"当前分类"前先弹「导出范围确认窗口」。**
> 走 **⇧ 导出 → 导出当前分类（JSON / Excel / HTML）** 时，会先弹出**结构树确认窗口**：
> - 窗口里列出**整个库结构树**：**项目类别 → 根目录 → 一级分类 → 二级分类**，每个分类后面的括号里是**该分类本级的条目数**；
> - 你在左侧**选中的那个分支及其全部下属**，在树里用**蓝色加粗**加重显示；
> - 窗口提示「**本次将导出：N 条**」——先核对这个数字；
> - 确认无误 → 点「**确认导出**」→ **才进入"选保存位置"的对话框**。
>
> **若你在左侧未选中任何级别 / 选项**：窗口会**红字**提醒"**尚未选择导出级别与选项**"，且「**确认导出**」按钮**灰色不可点**。此时请**关闭窗口**，回到左侧选中 **项目类别 / 根目录 / 分类** 之一，再重新点导出。
> **菜单「导出全部」不经过这个窗口**，仍是**一键直接导出**。

### 19.3 导入 JSON / Excel

1. 点 **⇩ 导入** → 选格式；
2. 选文件；
3. 软件会**先比对差异**（比如字段定义有冲突会弹对话框让你确认）；
4. 确认 → 导入（**导入前自动快照**）；
5. 完成后核对总数。

### 19.4 导入变更包

见[第 17.3 节](#173-怎么用它换机--给别人)。

### 19.5 结构化向导（**从乱七八糟的表格变成整整齐齐的书架**）

**什么时候用**：你有一堆表格 / 网页 / 文本，想批量变成 PromptSprite 里的条目。

**入口**：**⇩ 导入** → **从网址获取** / 或导入菜单里的"结构化导入向导"。

**五步走**：

| 步骤 | 做什么 |
|---|---|
| **第 1 步：选数据来源（三选一）** | ① **粘贴文本**（直接 Ctrl+V 贴进来）；② **本地文件**（`.csv / .tsv / .txt / .html / .md`）；③ **网址获取**（见 19.6） |
| **第 2 步：层级映射 + 字段映射** | 把你表格的**四列**对应到"项目类别 / 根目录 / 一级分类 / 二级分类"（**空单元格会自动继承上一行**，允许跳层）；再把你表格的列对应到 ①~⑩ 字段、自定义字段或标签 |
| **第 2 步底部"③ 可选增强"** | 四项开关（如自动补全相对链接、中英分流等） |
| **第 3 步：树预览 + 统计 + 质量自检** | 先看会生成什么结构；**质量自检面板**会报 7 项检查：数量对账、空值统计、同分类重名、兜底层级、链接补全、中英分流、规则"其他"占比 |
| **第 4 步：先保存数据文件** | **必须先把确认过的数据存成一个数据文件** |
| **第 5 步：再导入** | 导入前**自动快照**，出问题可一键回滚 |

> ⚠️ **重要**：如果你在"保存数据文件"之后又改了映射 / 换了表 / 换了来源，**需要重新保存**才能导入。这是为了保证"导入的一定是你刚确认过的那份数据"。

### 19.6 从网址获取（**只有你自己点了才会联网**）

**能抓什么**：网页正文表格、**GitHub 上的单个文件**、**GitHub 整个目录（批量）**。

**抓取特性**：
- **多通道自动降级**：raw → contents API → git blob（一条路不通自动换下一条）；
- **一个页面有多张表**时，会弹"选表"（默认选最大的那张）；
- **相对链接自动补全**（含 `blob → raw` 转换）；
- **反爬拦截页识别**（遇到会告诉你，不是默默失败）；
- 可以填 **Referer / Cookie**（在向导的「高级」里），应对部分站点；
- **超时 15 秒、单文件上限 10 MB**；GitHub 目录批量另有限额（单文件 ≤2MB、一次 ≤20 个、合计 ≤20MB，**个别失败会逐个跳过，不影响整体**）。

**抓不了什么**：需要 JS 渲染的页面、要登录的页面、有风控的站点、站内自动遍历。
**隐私承诺**：**一次性只读请求**——不写盘源文件、不留登录态、不后台访问、不做站内遍历。

### 19.7 原样搬运（不经过向导）

如果对方给你的就是 PromptSprite 的 JSON 或 Excel 文件 → 直接用 **⇩ 导入** 即可。

## 21. 常见问题 FAQ

### 21.1 我找不到 `data` 文件夹在哪

- 用 EXE：**就在 EXE 旁边**。在 EXE 上右键 → 打开文件所在位置，就能看到 `data`。
- 用源码：项目根目录下。
- 也可以在软件里：**⚙ 设置 → 关于 → 「ℹ 查看完整说明」**，里面写了"程序路径"和"数据文件"位置。

### 21.2 换了电脑 / 换了文件夹，为什么数据是空的（变成全新模板了）

因为 `data` 文件夹不在旁边，软件就新建了一个。**解决办法**：把原来的 `data` 文件夹整个复制到新位置（和 EXE 放一起），重新打开。

### 21.3 误删了数据怎么办

按顺序试这三招：
1. **回收站**：底部 ♻ 删除历史 / 回收站 → 找到 → 恢复；
2. **导入前快照**：`data\backup\prompts_preimport_*.db`；
3. **自动备份**：`data\backup\prompts_2026-09-XX_*.db`（挑日期最近的那个）。

**怎么用备份文件**：关软件 → 把当前 `prompts.db` 改名留底 → 把备份文件复制一份、改名为 `prompts.db` → 重开软件。

### 21.4 导入一个包之后，条目数反而变少了？！

你导入的是**"纯删除包"（负增量）**，而且选了"正常应用删除"。
**正确做法**：重新导入 → 在向导里选**"忽略删除（推荐）"**。
被删的条目如果在回收站里，也可以直接去回收站恢复。

### 21.5 为什么有些条目的"③~⑦"字段看不到？

两个原因，先分清：

| 原因 | 表现 | 怎么恢复 |
|---|---|---|
| **显示策略**是"自动"，而当前根目录不在完整显示名单里 | 只显示 ② 介绍 | 点详情区头部「⏵ 显示全部字段」，或把设置改成"全部显示" |
| 你**手动隐藏**过这些字段 | 详情区头部提示"**（另有 N 项已隐藏，可在「字段管理」中恢复）**" | 设置 → 字段 → 🔧 字段管理 → 把对应行改回"显示" |

### 21.6 删了条目，图片会一起没吗？

**不会立刻没**。删除只是进回收站，图片还留着。只有**彻底删除 / 清空回收站**时，图片文件才真正释放。

### 21.7 为什么点删除 / 保存 / 导入都是灰的、点不动？

三种可能：
1. 你处在 **👁 浏览**状态 → 点 **✏️ 编辑**；
2. 你开着 **🔒 锁定** → 再点一次解除锁定；
3. 你没选中任何条目 → 先在条目区点一条。

### 21.8 全局热键 `Ctrl+Shift+P` 没反应

可能原因（按概率排）：
1. 被别的软件占用了（比如某些输入法、截图工具）；
2. 需要**以管理员身份运行**才能监听全局键盘；
3. 被安全软件拦截。

**不影响使用**：直接在任务栏点软件图标一样能用。软件启动时热键注册失败也不会崩，会在状态栏提示。

### 21.9 软件打不开 / 启动闪退 / 没反应

依次试：
1. **看是否有安全软件拦截**（把软件目录加入白名单）；
2. **确认 `data` 文件夹可写**（不要放在只读目录，比如某些系统盘根目录、或受保护的公司共享盘）；
3. **确认磁盘没满**；
4. 用**源码方式**跑一次 `python -m app.main`，能看到报错信息（EXE 模式下看不到控制台）；
5. 把错误信息发到 [GitHub Issues](https://github.com/yihufree/PromptSprite/issues)。

### 21.10 状态栏出现"● 备份失败"

说明自动备份没成功。**请立刻手动复制一份整个 `data` 文件夹**（比如拷到 D 盘或 U 盘），然后检查：磁盘空间是否够、`data\backup\` 是否被设置成只读、是否有安全软件拦删文件。

### 21.11 找不到今天的"变更包"文件

- 变更包是**关闭软件时**才生成的——你还没正常关闭；
- 或者今天还没有任何变更——**没有任何变化的日子不会生成文件**；
- 路径：`data\backup\incremental\`。

### 21.12 Excel 文件太大，导入很慢 / 卡

正常现象。几千条要建几千个分类 + 几千条条目。建议：
1. **分批发**（比如一次 500 条）；
2. 导入期间**不要操作界面**；
3. 如果超过 5000 行，建议改用**结构化向导**（有质量自检、能提前发现问题）。

### 21.13 升级到 V2.0.0 / V2.1.0 / V2.2.0 后，我的老数据 / 老备份还能用吗？

**能用。**
- 老库：启动时**自动迁移**到 schema **v5**；
- 老备份（`prompts_*.db`）：可以照常用"数据比对"打开，也可以改名为 `prompts.db` 直接当主库用（会被自动迁移）；
- 老导出文件（JSON v2 / v3 / v4 / v5、旧 Excel、旧 MD）：**都能直接导入**（老包按"内容键"判重，行为与改造前完全一致）。

### 21.14 "从网址获取"联网抓取安全吗？能抓哪些、抓不了哪些？

**安全**：
- **只有你主动点**才会联网，其他任何时候都不联网；
- **只读**——只读取你给的那个网址，不写盘、不留登录态、不后台跑；
- 有超时（15 秒）和大小上限（10 MB）。

**能抓**：静态网页里的表格、GitHub 上的文件、GitHub 目录批量。
**抓不了**：需要 JS 渲染的页面、需要登录的页面、有反爬风控的站点、站内自动遍历。

### 21.15 为什么我（老用户）升级后没看到"预置标签"？

"预置标签"是**打在打包版内置示例库**上的，**只对"全新安装（用的是内置库）"的用户生效**。你自己的数据库不会被软件擅自打标——**这是为了保护你的数据**。
想让你的库也有标签：用 **🤖 批量打标**（建议先用"仅无标签的条目" + 小批量试水）。

### 21.16 批量自动打标会不会把我手工打的标签冲掉？能撤销吗？

- **不会**：把目标选成"**仅无标签的条目**"时，已经有标签的条目**根本不会被处理**；
- 就算选了"全部条目" + "覆盖"策略，**执行后也能精确撤销**——只回退这一次打标，不碰你后来做的修改；
- 而且软件**强制先预演 + 执行前自动备份 + 二次确认**。

### 21.17 我想让标签词表多一个"学术"大类，能自己加吗？

**能，而且不用改代码。**
1. 标签页面「词表」页签 → **⬆ 导出词表…**；
2. 用记事本打开 JSON，照着已有的领域包格式，在 `domains` 里加一个"学术"包；
3. **⬇ 导入（替换）…**（整份替换）或 **➕ 增量导入…**（只增不删）→ 完成。

### 21.17.1 只想给词表"加几个词"，不希望动到原来的词表，怎么做？

用 **➕ 增量导入…**（2026-09-17 新增）。做法：
1. 新建一个小 JSON（格式和导出的词表一样），里面**只写你想加的部分**，例如：

```json
{
  "version": 1,
  "universal": { "领域": { "视觉": ["赛博朋克"] } },
  "domains": { "视觉": { "风格流派": { "赛博朋克风": ["cyberpunk"] } } },
  "domain_map": { "视觉": ["赛博朋克"] }
}
```

2. 点 **➕ 增量导入…** → 选这个文件 → 确认框会告诉你"将新增标签 1 个、匹配词 2 个；现有 809 个标签全部保留" → 确定即可。

要点：**只需写"新增的那些"**，出厂/现有词表原样保留；同名标签下已有的词不会重复。

### 21.18 自动取词词库里堆了一堆词，我需要管吗？

**不必须管**，它自己会干活：
- 达到"热点阈值"的会**自动**变成热点词（下次打标就命中）；
- 达到"词表阈值"的**只是提示你**，你不理它也不会有任何副作用；
- 觉得吵的话：可以在设置里把"取词用于批量打标"打开、或把阈值调高、或直接在对话框里 🧹 清空。

### 21.19 详情区有个字段莫名其妙不见了

先看**详情区头部的状态行**：如果写着"**（另有 N 项已隐藏，可在「字段管理」中恢复）**"，就是被手动隐藏了 → 设置 → 字段 → 🔧 字段管理 → 改回"显示"。
如果没有这行提示，那就是"显示策略"导致的（见 21.5）。

### 21.20 我把字段顺序调乱了，怎么恢复默认？

目前没有"一键恢复默认顺序"的按钮。手工办法：进字段管理，用 ↑↓ 按 ①→②→③…→⑩、🏷 标签、🧭 位置、🕒 时间的顺序排回来即可。**建议调顺序前先记一下原来的顺序。**

### 21.21 删除项目类别的专用口令是什么？（2026-09-22 新增）

- **公开默认口令是 `123456`**（**仅**在删除「项目类别」时需要，并且要先**手工输入该项目类别的完整名称**）；
- 它只是**"多一道手工关卡"**，用来防手滑、防误操作，**不是安全防护**（详见第 22 章第 20 条）；
- 忘了也不怕：**设置 → 关于**页已**直接显示这个口令**，「ℹ 查看完整说明」窗口内**同样可以查到**；
- **真正的数据兜底不是口令，而是**：删除前的**双重自动备份**（全量库快照 + 待删分支 JSON）与**回收站**——选「软删除」时被删条目可恢复。

### 21.22 批量删除会不会误删其他根目录的数据？（2026-09-22 新增）

**不会。** 软件按"**共享分类只解除关联、条目看位置**"的口径处理：
- 被**其他根目录共享**的一级分类，**只解除关联、不删除分类记录**，**其他根目录仍然可以正常访问它**；只有**仅属于本分支**的分类才连同其子树一起删除；
- 一条条目只有在它的**全部位置**都落在本次删除范围内时，才删除**条目本体**；只要还有**一个位置在范围之外**，就**只删除范围内的位置关联，条目本体保留**；
- 此外，删除前会**自动做双重备份**（**任一备份失败即中止、不写任何数据**）；选「软删除」的条目还能从**回收站**恢复。完整步骤见第 9.4 节。

**1. 导出范围确认窗口（新）——导出当前分类前先"看清范围"**

- **在哪**：顶部工具栏 **⇧ 导出** → **导出当前分类（JSON / Excel / HTML）** → **先弹"结构树确认窗口"**。
- **窗口里看到什么**：
  - **整个库结构树**：**项目类别 → 根目录 → 一级分类 → 二级分类**，每个分类后的括号内是该分类**本级的条目数**；
  - 你在左侧**选中的那个分支及其全部下属**用**蓝色加粗**加重显示；
  - 提示「**本次将导出：N 条**」。
- **怎么用**：核对"N 条"无误 → 点「**确认导出**」→ **才进入"选保存位置"对话框**。

- **例外**：菜单「**导出全部**」**不经过这个窗口**，仍是**一键直接导出**。（另见 §19.2）

**2. 批量删除本分支全部数据（新）——六道关卡**

- **在哪**：左侧导航右键「**项目类别 / 根目录 / 一级分类 / 二级分类**」→「**🧹 批量删除本分支全部数据…**」。
- **六道关卡（顺序固定，任一步取消即中止）**（完整步骤表与"删除口径"见 **§9.4**，此处只列纲要）：
  ① **影响范围统计弹窗**（将删除的分类记录数 / 需解除关联的共享分类数 / 删除的根目录数 / 处置本体的条目数 / 仅解除位置关联的条目数）→ 确认后进入下一步；
  ② **手工输入确认短语**「**删除全部下级内容**」；
  ③ **选择删除方式**：**软删除**（条目移入回收站、可恢复，**推荐**）/ **硬删除**（条目彻底删除、**无法从回收站恢复**）/ 取消；
  ④ **仅当删除「项目类别」时**：另需**手工输入该项目类别的完整名称**，再输入**专用口令**（公开默认口令 **123456**）；
  ⑤ **自动双重备份**：全量库快照 `data/backup/prompts_predel_<时间戳>.db` + 待删分支全部数据 `data/backup/prompts_branch_<分支名>_<时间戳>.json`；**任一备份失败即中止删除、不写任何数据**；
  ⑥ **执行删除并自动刷新**左侧导航与条目区。
- **删除口径**：· **被其他根目录共享的一级分类只解除关联、不删除分类记录**（其他根目录仍可正常访问它）；只有**仅属于本分支**的分类才连同其子树一起删除。· **条目只有在"全部位置"都落在本次删除范围内时才删除条目本体**；只要还有位置在范围之外，就只删除范围内的位置关联、**条目本体保留**。

## 24. 术语小词典

| 术语 | 大白话解释 |
|---|---|
| **条目** | 一条提示词记录（含 ①~⑩ 字段、标签、图片等） |
| **五级分类** | 项目类别 › 根目录 › 一级分类 › 二级分类 › 条目，一层层往下分 |
| **项目类别** | 最上面那一层（如"网上资源收集"） |
| **根目录** | 第二层（如"视频""图像"），有时也叫"领域" |
| **多位置条目** | 一条内容同时挂在好几个分类里（"关联"出来的），改一处全同步 |
| **标签** | 贴在条目上的便利贴，一条可以有多个；和分类（只能一个位置）互补 |
| **显式标签** | 条目内容里自己写明的「标签：xxx」 |
| **取词** | 软件直接从 ①名称 / ⑧中文 / ⑨英文里"切"出词来当标签 |
| **词表** | "什么词算哪个标签"的规则表 |
| **热点词表** | 你特别关注的词，打标时优先匹配 |
| **自动取词词库** | 装"软件发现的新词"的地方，用得多了就自动升级成热点词、或提示你收进词表 |
| **批次** | 一次批量打标操作，可以整体撤销 |
| **预演** | 先"假打一遍"给你看结果，不动真数据 |
| **精确撤销** | 只回退某一次批量打标，不影响你后来的修改 |
| **变更包** | 记录"今天改了什么"的文件，可以拷到别的电脑合并 |
| **负增量 / 纯删除包** | 删除数比新增数大得多的变更包；导入时要特别小心 |
| **逆向恢复** | 把变更包里的"已删除条目"反向加回来 |
| **快照** | 某个时间点数据的完整复印件（后悔药用） |
| **回收站** | 删掉的东西先放这儿，可以还原 |
| **硬隐藏** | 详情区某块被手动藏起来了；普通"显示全部字段"也恢复不了，要去字段管理里改 |
| **虚拟区块** | 🏷 标签 / 🧭 位置 / 🕒 时间 这三块——不是条目的真实字段，只是详情区的显示区；能排序、能隐藏，但不能改名、不能删 |
| **schema v5** | 数据库结构的版本号（当前为第 5 版；v5 给每个条目加了"稳定 ID"） |
| **JSON v6** | 导入导出文件格式的版本号（当前为第 6 版；v6 起导出包带"稳定 ID"和"位置清单"） |
| **稳定 ID（uuid）** | 每个条目一个跨机器唯一的 32 位编号；换机同步时靠它认出"这是同一条"，因此"修改"才是真的修改同一条 |
| **CTk / CustomTkinter** | 这个软件用的界面外观库 |
| **PyInstaller** | 把 Python 程序打包成 EXE 的工具 |
| **防抖** | "等你停下来再做"的技术（如搜索等 1.5 秒、悬停等 0.2 秒） |

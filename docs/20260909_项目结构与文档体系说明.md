# 项目结构与文档体系说明

> PromptSprite **V2.0.0（2026-09-14）** · 本文件为仓库结构速览，供维护者与协作者快速定位代码与文档。
> 本轮（V2.0.0）库结构升到 **schema v4**（新增 6 张表）、导入导出格式升到 **JSON v5**，并新增标签系统、条目图集、自定义字段与 11 种字段类型、网上资源结构化向导（含联网抓取与 GitHub 目录批量）等模块；均为"纯新增 + 向后兼容"，旧数据/旧备份/旧导出文件均可直接使用，数据文件名未变、无需迁移。软件版本上一版为 V1.9.0（2026-09-12）。

## 一、项目结构（精简）

```
PromptSprite/（GitHub: https://github.com/yihufree/PromptSprite，MIT，仅供学习与个人使用）
├── app/                          # 主程序包（技术栈：Python 3.12 + CustomTkinter + SQLite）
│   ├── main.py                   # 程序入口：静默备份→建库→内置库/迁移向导→热键/托盘
│   ├── config.py                 # 全局常量：版本号、目录、备份/变更包策略、meta 键
│   ├── database.py               # SQLite 数据层：projects/domains/categories/entries/meta/
│   │                             #   entry_links / deletion_log(payload) / trash(回收站)
│   │                             #   schema v4 新增 6 表：field_defs / entry_field_values /
│   │                             #   entry_ref_links / tags / entry_tags / entry_images
│   ├── models.py                 # 数据模型（Entry 字段/时间戳/收藏等）
│   ├── backup.py                 # 自动全量备份（按天去重、默认30份）+ 导入前快照
│   ├── incremental_backup.py     # 每日变更包（JSON v5、addN_delM 命名、随包携带 field_defs、携带快照可选）
│   ├── hotkey.py                 # 全局热键 Ctrl+Shift+P + 系统托盘
│   ├── self_test.py / gui_self_test.py   # 自测与 GUI 冒烟
│   ├── parser/                   # md_parser / json_io(v2~v5、四层路径、field_defs 随包、逆向恢复) /
│   │                             #   excel_io（自定义字段/标签/图集/项目类别列）/ html_export /
│   │                             #   fetcher（联网抓取，纯标准库）/
│   │                             #   hierarchy_import（四层结构化 + 质量自检 + 选表/合并）
│   ├── ui/                       # main_window（标签区块/标签页面、图集、11 类字段控件、详情显示模式）、
│   │                             #   change_import_dialog（变更包导入向导）、compare_dialog（数据比对）、
│   │                             #   history_dialog（回收站/新增历史）、import_wizard_dialog（结构化向导）、
│   │                             #   github_batch_dialog（GitHub 目录批量多选）、
│   │                             #   field_manager_dialog（字段管理与列表框数据源）、
│   │                             #   field_defs_diff_dialog（字段定义差异确认）、
│   │                             #   quick_add、copy_move_dialog、move_selector、migrate_dialog、
│   │                             #   project_chooser、progress_dialog、settings_dialog
│   └── resources/                # builtin_manual.md（内置手册）、builtin_prompts.db（打包内嵌）
├── docs/                         # 本文档体系（见下表）
├── Icons/                        # 应用图标源（PSicon.png）
├── build.py / run.py / requirements.txt   # 一键打包 / 启动器 / 依赖
├── data/                         # 运行时生成（.gitignore 忽略）：prompts.db、backup/、
│                                 #   backup/incremental/、images/
├── *.json / *.xlsx               # 数据资产示例文件（可直接导入）
├── 2026xxxx_PromptSprite_0N_开发工作记录.md   # 开发记录（根目录）
├── Dev_Work_Log/                 # 开发记录手工版/TRAE 版与历史归档（勿删改）
└── LICENSE / README.md / .gitignore
```

要点：数据层与 UI 解耦（database.py 单点读写，回收站/迁移/删除均可复用）；`data/` 不入库且打包态位于 EXE 同目录；`README.md` 为对外总入口。

## 三、维护约定

1. 开发工作记录一律**追加**（按轮次编号），不覆盖、不删除；源码修改处添加 `修改日期+内容` 注释。
2. 文档修订遵循"先方案/需求 → 代码 → 说明书/打包指南/README 同步 → 打包归档"的顺序；发布前 README 与 docs 版本保持一致。
3. 数据/导入/删除类高风险改动需先在审核报告与开发记录中列明影响面。

# 🧩 PromptSprite（提示精灵）

> AI 提示词管理工具 —— 把杂乱无章的 Prompt 文档，变成 **五级分类书架 + 极速检索 + 一键复制 + 回收站（可恢复）+ 每日变更包 + 导入安全防护** 的本地神器。

双击 `PromptSprite_<打包日期YYMMDD>_V2.2.0.exe` 即可使用（**当前源码版本 V2.2.0；已发布最新版，**以 Releases 页最新标注为准**）。

> ⚠️ **V2.2.0 已打包发布**（2026-09-21 ）。V2.2.0 的变更是"数据格式升级"（库结构 schema v5、导出 JSON v6）。

> 📁 **请把它放在一个稳定、可写、不会被误删的文件夹**（不要放桌面或"下载"文件夹），**数据就存在 EXE 同目录的 `data/` 里**——换文件夹/换电脑时，**把整个 `data` 文件夹一起复制过去**即可。
> 🔐 数据 100% 存在本机（明文 SQLite，**不含加密**，如有隐私需求建议配合 BitLocker 等系统级磁盘加密）；**只有你在向导里主动使用「从网址获取」、或在标签页面使用「热点词更新」时才会联网**（只读抓取你填写的网址，不写盘、不留登录态），其余功能全程离线。

## 🚀 快速开始

### 方式一：直接使用（普通用户）

1. 从 [GitHub Releases](https://github.com/yihufree/PromptSprite/releases) 下载 `PromptSprite_<打包日期YYMMDD>_V<版本号>.exe`（**当前源码版本为 V2.2.0，但尚未打包发布**；已发布产物为 `PromptSprite_260916_V2.1.0.exe`，**以 Releases 页最新标注为准**）；
2. **放到一个你记得住、不会被误删的文件夹**（**不要放桌面或"下载"文件夹**），双击运行（首次自动建库并导入内置数据；数据保存在 EXE 同目录 `data/` 下）；**换文件夹时请把原来的 `data` 文件夹一起复制过去**；
3. 详细图文说明见 [《软件安装使用说明书 V12》](docs/20260917_软件安装使用说明书_v12.md)。

### 方式二：源码运行（开发者）

```powershell
# 1. 克隆仓库
git clone https://github.com/yihufree/PromptSprite.git
cd PromptSprite

# 2. 创建虚拟环境并安装依赖（Python 3.12，兼容 3.10+）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. 启动（以下三种方式等价）
python app/main.py        # 直接运行主文件（推荐）
python run.py             # 根目录启动器
python -m app.main --smoke    # 冒烟测试：5 秒后自动退出
```

运行依赖：`customtkinter` / `Pillow` / `pyperclip` / `openpyxl` / `keyboard` / `pystray`（见 [requirements.txt](requirements.txt)，直接运行主文件缺依赖时会自动安装）。

### 📦 打包发布

```powershell
python build.py           # 一键打包（自动装依赖/生成图标/内嵌最新完整库/PyInstaller 单 EXE/校验）
```

产物自动按 **`PromptSprite_<打包日期YYMMDD>_V<版本号>.exe`** 命名（本机 2026-09-17 实测：`dist\PromptSprite_260916_V2.1.0.exe`，**23.54 MB**，单文件、无控制台窗口；**体积与 SHA256 随每次构建而变**）。详见 [《打包发布指南 V11》](docs/20260917_打包发布指南_v11.md)。

> V2.1.0 ~ **V2.2.0**（含 2026-09-15 / 09-16 / 09-17 三批增强）**均未新增任何第三方依赖**（智能标签 / 批量打标 / 词表 / 热点词 / 自动取词 / 条目稳定 ID 均用标准库），因此**打包流程与 `spec` 无需任何改动**；

## 🗄️ 数据与隐私

- **100% 本地**：单文件 SQLite 数据库 `data/prompts.db`；打包态为 EXE 同目录 `data/`，开发态为项目根 `data/`。软件**不上传、不收集任何数据**；唯一的联网行为是你在结构化向导里**主动**使用「从网址获取」时按你填写的网址做**只读抓取**（不写盘源文件、不留登录态、不后台访问、不做站内遍历）。
- **图片与备份**：条目关联图片存 `data/images/`；自动全量备份与导入前快照存 `data/backup/`；每日变更包存 `data/backup/incremental/`。
- **数据模型**：项目类别/根目录/一级/二级/条目五级；分类为全局共享树，删除根目录仅解除关联；`trash` 表保存被删完整快照（可恢复）；旧库启动自动迁移（v1→v2→v3），`deletion_log` 老库自动补 `payload` 列（V1.7.0）。
- **隐私提醒**：变更包可能包含条目内容与删除清单；"携带被删快照"默认关闭，分发/导入前请先查看摘要确认（纯删除包会有红字警告）。

## ⚠ 已知限制与说明（2026-09-10 V1.8.0 复核；2026-09-14 V2.0.0 补充；2026-09-17 **V2.2.0** 补充）

> 完整版（含每条限制的应对办法）见 [《软件安装使用说明书 V12》第 22 章](docs/20260917_软件安装使用说明书_v12.md)。

1. **搜索的 1.5 秒延迟是刻意设计**：V1.8.0 起输入过程不实时查询（避免整库刷新卡顿），停止输入约 1.5 秒后才搜索；要"立刻出结果"请点搜索框右侧 **🔍** 或按回车。
2. **窗口最小宽度会随目录显隐变化**：四列全显示时约 1496、四列全隐藏时约 1104（该下限由顶部工具栏"完整显示所需宽度"决定，低于它"导入/导出/设置/搜索"会被挤出可视区）。若把窗口从"目录全隐藏"的窄宽度直接恢复显示四列，窗口会被最小宽度自动顶宽。
3. **多位置条目的导出往返（2026-09-17 起已修复）**：v6 起，子树导出时多位置条目**只写一次**、位置清单写入 `locations`，导入时自动重建关联 ⇒「1 条 + N 位置」**保真**。**例外**：**Excel** 仍按行展开（人看/人改友好），但导入时按 `uuid` 合并，不会再产生副本；若表格被人为删掉了 `uuid` 列，则退回"内容键"判重（老行为）。
4. **数据比对口径（2026-09-17 已改进）**：条目"内容已修改"的配对**优先按稳定 ID（uuid）**——同一条目即使改名又改内容也会准确报成"内容已修改"（备注标"按稳定 ID 配对"）；**老备份库**（无 uuid）自动回退原口径：条目差异按"详情内容键（content_key）"识别，同名不同内容会被视为不同条目，内容一致但位置不同的两条视为同一条（已按分类 id 修复同名分类互相覆盖问题）。
5. **"修改"的换机同步语义（2026-09-17 起已修复）**：条目自 schema v5 起带**跨机器稳定 ID（uuid）**，变更包/JSON 导入优先按 uuid 匹配 ⇒「修改」真正同步为**更新同一条目**（条目数不再增长）。**旧包（v2~v5，无 uuid）行为完全不变**：仍按内容键判重合并。
6. **详情"自动"显示模式**：默认仅对 **视频 / 图像** 两个根目录完整显示 ②~⑦，其余根目录（音频、文学、学术、专业报告、各项目类根目录等）只显示 ② 介绍；点详情头部"⏵ 显示全部字段"（会话内临时覆盖）或把设置改为"全部"即可全显。
7. **类型为"标签"的自定义字段按文本保存**（多个用逗号分隔）：这样能被全局搜索、导出与换机变更包**自动覆盖**；若需要"字段级独立标签体系"（可在标签页面按该字段聚合）需要另行改造。
8. **"图像"类型自定义字段**：为"路径 + 选择/打开 + **内嵌缩略预览**"（本地图在输入行下方显示，最大 220×150）；**外链图不下载预览**（省流量、保持离线安全），请点"打开"用浏览器查看；路径不存在时显示灰字占位。
9. **结构化向导的出口为"先保存数据文件、再导入"**：保存后若又改了映射/换表/换源，需重新保存才能导入（确保导入的一定是你刚确认过的那份数据）。
10. **联网抓取的边界**：不支持需要 JS 渲染的页面、不处理登录流程、不做风控绕过、不做站内自动遍历；部分站点需在向导「高级」里补 Referer / Cookie 才放行。抓取仅为**你主动触发的一次性只读请求**（15 秒超时、体积上限 10MB；GitHub 批量另有限额）。
11. **详情区"区块顺序"与"隐藏"是本机显示偏好**（2026-09-16 新增）：存在本机数据库的设置项里，**不随 JSON 包 / 变更包导出**——换到另一台电脑需重新排一次 / 隐藏一次；用**本机备份**恢复会带回该设置。**被隐藏的区块内容不会丢**（照常导出、搜索、进变更包），切换隐藏状态也不影响导入导出。
12. **"手动隐藏"与"显示模式"优先级**（2026-09-16 新增）：字段管理里的「隐藏」是**硬隐藏**——无论"详情字段显示"设为自动 / 全部 / 精简，被隐藏的区块都不显示，详情区头部「⏵ 显示全部字段」也**不会**把它显示出来（只能回字段管理改回"显示"）；若发现"字段不见了"，先看详情区头部状态行是否提示"另有 N 项已隐藏"。
13. **① 名称在详情区使用固定标题**（既有行为，2026-09-16 补充说明）：字段管理里可以给 `name` 改名，但详情区 ① 的标题恒为「① 条目名称（风格名称）」，不受改名影响；① 也不参与排序、不能被隐藏。
14. **数据库为明文 SQLite，不含加密**（2026-09-17 补充披露）：本机其它程序理论上可读取 `data/prompts.db`。**如有隐私需求，建议配合系统级磁盘加密（Windows BitLocker 等）**；软件不会上传任何数据。
15. **全局热键可自定义（2026-09-17 更新）**：默认 `Ctrl+Shift+P`，可在 **设置 → 数据与备份 → 全局热键** 改为其它组合（如 `alt+f1`，必须含修饰键），**保存后立即生效**；留空即恢复默认。注册失败多因被其它软件占用或缺管理员权限，**不影响其它功能**（可点任务栏图标）。
16. **自动取词的"词表阈值"提示只在管理对话框内出现**（2026-09-17 补充）：软件不会主动弹窗提醒，请偶尔打开"设置 → 标签与词表 → 🧠 自动取词词库…"查看"待审核"数量。
17. **调整字段顺序后没有"一键恢复默认"**（2026-09-17 补充）：需手工用 ↑↓ 排回，**建议调整前先记录原顺序**。
18. **软件应放在一个稳定、可写、不会被误删的文件夹**（2026-09-17 补充）：**不要放桌面或"下载"文件夹**；`data` 文件夹必须与程序同目录。换文件夹时请把原来的 `data` 一起复制过去，否则会新建空库。
19. **打包脚本含硬门禁**（2026-09-17 补充）：`python build.py` 第 4.5 步会调用 `clean_builtin_meta.py` 清理并复核内嵌库的"运行态 meta"（含开发机计算机名等），**任一步失败会直接终止打包**——这是防止开发机信息随 EXE 出厂的刻意设计，请勿绕过。
20. **库结构已升至 schema v5 / 导入导出格式升至 JSON v6（2026-09-17 起，重要）**：v5 只给 `entries` 增加 `uuid` 列并回填（**不改任何既有字段语义**、不动其他表）；v6 只是在导出包里增加 `uuid` 与 `locations` 两个键。**旧库启动自动迁移（幂等，迁移前自动备份）**；**但回退到旧版 EXE 时必须同时恢复数据库备份**——旧版不认识 v5 结构。老导出文件（JSON v2~v5、旧 Excel、旧 MD）**照常可用**，导入行为与改造前完全一致。
